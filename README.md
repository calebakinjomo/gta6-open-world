# Velora Bay

An original 2D top-down open-world crime browser game set in the fictional city of Velora Bay. Play as Danny Cole, a driver pulled back into the life, and run five story missions for crew boss Marisol Vega against the rival Kestrels. Steal cars and thread them through live traffic, dodge or outrun the police wanted system, fight on foot when things get loud, and watch it all on the HUD and minimap. Progress saves to localStorage, so the city remembers you.

## Features

- Open city to explore on foot or behind the wheel
- Five story missions from Marisol Vega against the Kestrels
- Stealable cars, live traffic, and pedestrians
- Police wanted system with chases
- On-foot shooting, HUD, and minimap
- Progress saved in localStorage

## How to play

Run `node serve.ts` and open http://localhost:8080, or open `game/index.html` directly in a browser.

- **WASD / arrow keys** — move on foot, drive when in a car
- **Mouse** — aim
- **Click** — shoot
- **E** — enter / exit cars
